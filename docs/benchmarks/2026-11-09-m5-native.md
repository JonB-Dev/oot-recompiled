- Native means 2560×1440 on the connected M27Q at 60 Hz. Apple M5 (10 GPU cores), 32 GiB, macOS 26.7.1; AC power, Low Power Mode off. The earlier internal-display results are a different workload.
- Full-detail OoT Reloaded v11 RT64, Original 20 fps, fullscreen, native resolution, expanded aspect, downsampling off, level-2 tracing, and original draw distance were used. No game image upscaling, texture-detail reduction, or tracing-tier reduction was used in the native comparisons.
- An isolated child/noon scene-probe save was used, with opening cutscene and Saria’s greeting skipped. File 1 and backup checksums were maintained. This is a stationary scene benchmark, not broad progression or a controller-play session. Inputs only enter file 1; the same starting view was used within each scene. The connected physical controller was not used for the automated benchmark.
- The baseline used runtime `16d8aeb`; the menu/preset changes use runtime `0c48b7f`. No renderer optimization is claimed. The improvement is a measured selection of quality settings and an in-app way to apply them. Experimental 8× AA / eight AO rays was rejected because Kakariko missed the target.
- Comparison windows use probe sample indices 69–92 inclusive, after startup and shader/texture warm-up. Presents are actual presented frames per probe interval (approximately one second); the presentation mean is a mean of one-second interval means. Worst presentation interval is measured directly by the probe. No frame-percentile statistic is inferred from these aggregates.
- Every run was guarded by the existing Metal-fault and 4096 MiB process-RSS watchdog. No frame recording was enabled in timed trials. Thermal state was not fixed and trials were sequential; matched settings, scene, display, and power were maintained. Five-minute observation does not establish hours-long or whole-game stability.
- To reproduce, an isolated writable profile with a valid file-1 save and a separately obtained RT64 pack is required. A fresh child opening save can be copied safely with `python tools/make_macos_playable_test_save.py /path/to/opening-save.bin build/native-test --skip-saria-greeting`. The original save is not changed. The pack can be placed or linked under that profile’s `texture-packs/`, then selected in the app opened with `--data-root "$PWD/build/native-test"`. Select Native detail in Graphics. Noon is required to match the recorded scene lighting; other save states are separate workloads.
- The Kakariko run can be repeated with `python tools/smoke_macos_gameplay.py /path/to/USA-1.0.z64 --data-root build/native-test --enter-save --entrance 0x0DB --raytracing --rt-level 2 --seconds 300 --max-rss-mib 4096 --probe outputs/native-kakariko.probe.txt`. Hyrule Field uses `--entrance 0x0CD`. A probe directory must exist. The interpreter from an available Conda environment can be used.
- The comparison window can be checked with `python tools/summarize_macos_probe.py outputs/native-kakariko.probe.txt --first 69 --last 92`. Missing or nonfinite samples are rejected. The longer warm window can be checked by changing the bounds to the recorded range.
